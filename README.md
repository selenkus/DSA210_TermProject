# DSA210_TermProject
## An Exploratory Analysis of Turkish TV Series Ratings and Prediction Using Machine Learning Models

### Project Overview
- This project analyzes Turkish TV series data using Exploratory Data Analysis (EDA), hypothesis testing, and machine learning techniques. The goal is to understand which factors influence IMDb ratings of Turkish TV series.

The project includes:
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Hypothesis testing
- Machine learning models for the prediction of ratings
- Feature importance analysis

---

## Dataset
The dataset contains information about Turkish TV series, including:
- Title
- IMDb rating
- Genres
- Number of votes
- Start year
- Runtime in minutes

Dataset file:
- turkish_dramas_publishable.csv

## Methods Used

### Exploratory Data Analysis (EDA)
- Summary statistics
- Correlation analysis
- Visualization of ratings, votes, genres, and runtime

### Hypothesis Testing
Several statistical tests were performed to examine relationships between variables.

### Machine Learning
Two regression models were used:
- Linear Regression
- Random Forest 

The models were used to predict IMDb ratings based on:
- Votes
- Start year
- Runtime
- Genre information

---

## Main Findings
- Votes were the strongest predictor of IMDb ratings.
- Random Forest performed better than Linear Regression.
- Genre information slightly improved model performance.
- The overall prediction performance remained moderate, indicating that additional variables may be needed.
